# Nutriplan Website

A simple, responsive single-page website for Nutriplan — a nutrition and meal-planning service. This repository contains the static frontend built with HTML, CSS, and JavaScript.

## Features

- Responsive landing page
- Client-side JavaScript for interactivity
- Modular assets located in src/

## Technologies

- JavaScript
- HTML
- CSS

## Getting started

This is a static website. You can open it directly in a browser or serve it with a simple static server for local development.

Option 1 — Open locally
1. Clone the repository:
   git clone https://github.com/MAzenMOhamed940/Nutriplan-Website.git
2. Open `index.html` in your browser.

Option 2 — Serve with a static server
- Using Python 3:
  ```bash
  python3 -m http.server 8000
  # then visit http://localhost:8000
  ```
- Using npm http-server:
  ```bash
  npm install -g http-server
  http-server -p 8000
  # then visit http://localhost:8000
  ```

## Development

- Edit HTML, CSS, and JS files in the repo. The main entry point is `index.html`.
- Assets and modular scripts are inside the `src/` directory.

## Project structure

- index.html — main page
- src/ — JavaScript, CSS, images, and other assets
